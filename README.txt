REDCORE HOSTING - FRONTEND

Files:
- index.html
- style.css
- script.js

This is a frontend-only hosting website.
No backend, database, authentication, payment gateway, or real server provisioning is included.

GitHub Pages:
1. Create a GitHub repository.
2. Upload these 3 files.
3. Go to Settings > Pages.
4. Select Deploy from branch.
5. Select the main branch and /root.
6. Save.

The site will work as a static website.
